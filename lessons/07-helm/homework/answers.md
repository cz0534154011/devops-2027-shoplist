# שיעור 7 – תשובות

# 1
chart מכיל הגדרות כלליות של כל הפרויקט היכולים להשתנות מהתקנה להתקנה יכול להיות מותקן כמה פעמים
relese  מכיל את הגדרות של פתיחת הפרויקט זה למעשה ההרצה בודדת של מה שהוגדר בתוך chart
בפרויקט שלנו:
chart = name: shoplist
relese = Name: shop

# 2
